# SOLO website image sources

The editorial photographs currently referenced by the static pages are served from Unsplash image CDN URLs (`images.unsplash.com`). Unsplash’s license permits use and modification subject to its terms. The website does not use retailer product imagery, retailer logos, or Amazon Associates assets.

Before production launch, verify each selected image and its current license/terms, then preferably store optimized local copies with the corresponding photographer/source details here. If remote images fail, the shared stylesheet and page-level fallback styles preserve the layout and show a neutral SOLO fallback treatment.
