Privacy

A small, clear privacy note.

This is a static editorial website. It has no account system, analytics, advertising pixels or server-side contact form.

Information you provide

The contact page does not ask for or transmit personal information. It explains that no contact address has yet been configured. This website does not intentionally collect or store form submissions.

Technical requests

When hosted, the hosting provider may process standard connection information such as IP address, browser details and requested page to serve and secure the site. Review the selected host’s current privacy and logging terms before launch.

External images and type

Editorial photographs are referenced from Unsplash’s image CDN and the typeface is loaded from Google Fonts. When a browser requests those assets, the respective providers may receive technical request information under their own policies. Local image fallbacks are provided if an image request fails.

Cookies, analytics and journal search

The site does not intentionally set cookies, use analytics or run advertising trackers. Journal search and category filtering run in the browser; the search terms are not sent to SOLO.

Changes

If the site later adds analytics, a working form, accounts, or other data processing, this policy should be updated before those features are enabled. For the current contact status, see Contact.
